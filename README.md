# 거지키우기_k

제작자 **KSW** · 바탕화면 방치형 클릭 게임

- `index.html` — 게임 본체. 실행기가 실행될 때마다 여기서 최신 버전을 받아가요.
- PC: `거지키우기_k.html`(실행기)과 `거지키우기_k.bat`을 같은 폴더에 두고 `.bat` 실행
  - `.bat` 맨 위 `GEOJI_OPACITY`(투명도 20~100, 기본 75)와 `GEOJI_TOP`(1 = 항상 위)로 창을 조절할 수 있어요
- 폰: GitHub Pages 주소로 바로 플레이

이 저장소에 `index.html`이 업데이트되면 모든 플레이어가 다음 실행 때 자동으로 패치돼요.
